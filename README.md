# 2027 考研政治 · 错题知识库

纯静态复习站点：90 页练习册照片、105 个模块级考点、两轮测验弱项统计、五门课体系化考点卡。

- **总览**：薄弱地图、优先级、考频 × 错误率四象限
- **题库统计**：90 页全量题目计数、考点频次、题边笔记、错题统计
- **知识树**：马原 / 毛中特 / 新思想 / 史纲 / 思道法
- **错点卡**：为什么错、正确逻辑、易混对照、记忆钩子
- **错题本**：照片中有明确批改证据的错题
- **高频易错榜**：多错 + 多考的考点排序
- **对比记忆**：横向易混概念对照 + 纵向知识链条 + 题边旁注摘录
- **抽认卡**：主动回忆，本机记录进度

包含 90 页练习册的 OCR 题目文字版和派生文字；不包含原图、PDF、长段教材原文或个人信息。

> 所有考点统一显示为“模块·考点号”（如 马原·考点46、新思想·考点46），数据键也是模块级唯一 ID；错误率来自两轮小样本测验，不等同于真实考试概率。  
> 练习册没有答案页，错题的正确答案为 AI 依据题干、选项、批改痕迹推断，页面标为“AI推断”，不等同官方答案。
